# Offload Security

**Offload Security is a unified CNAPP, vulnerability management and compliance platform that consolidates findings across cloud, code, containers, Kubernetes, applications, on-premises infrastructure and Wazuh-monitored endpoints into one governed risk view.** These docs help you onboard, configure and operate it, as SaaS or fully on-premises.

## What you can do with it

Offload Security is organized into five areas that map directly to the product's left-hand navigation. Each line links to the section of these docs that covers it.

### Core Security
Run and review security testing from one place.
- **Dashboard** — security posture, metrics and top risks at a glance; the **Executive Dashboard** tab for leadership — [Reports & AI](./reports-and-ai/index.md).
- **Scanning** — one module with three tabs: **Assessments** (App Scan: an authenticated, graded web and API assessment across up to 13 tools), **Targeted runs** (one tool at a time: OWASP ZAP, Nuclei, nmap, testssl.sh, security headers, API discovery, OWASP API Top 10, domain reconnaissance) and **New scan**, the one launcher. Every run records what ran and who authorized it, keeps the raw tool output, and can be compared with the previous run of the same target — [App & Infrastructure Scanning](./security-scanning/index.md).
- **Code Command Center** — SAST, secrets detection, dependency (SCA) and IaC scanning, SBOMs with **license compliance**, SARIF import from other scanners, pull and merge request review; agent-written fix pull requests are off by default (`AGENTIC_FIX_ENABLED`) — [Code Security](./security-scanning/code/index.md).
- **Infra Command Center** — endpoint security from a Wazuh you connect (agents, alerts, vulnerabilities, file integrity, logins, an **Endpoint 360** page per host) and network VAPT results imported from Greenbone OpenVAS — [On-Premises](./on-premises/index.mdx).
- **Vulnerability Management** — one triage queue across every source, risk scoring, SLA tracking, deduplication, approved and time-limited **risk exceptions**, a per-finding case file, remediation guidance — [Vulnerabilities & Risk](./vulnerability-risk/index.md).
- **Security Command Center** — the AI-assist view of the same triage queue: agents that triage, prepare fix suggestions and answer posture questions, with an approval-gated Auto-Fix Engine whose cloud actions are simulated unless the operator enables live execution — [Security Command Center](./ai-threat-intelligence/ai-soc-agents.md).
- **Alerts** — the unified alert stream from every module, with delivery to Slack, Teams, Google Chat and PagerDuty, and a daily SOC email digest instead of per-alert email — [Alerts](./vulnerability-risk/alerts.md).

### Cloud & Infrastructure
Continuously assess everything you run in the cloud.
- **Cloud Security (CSPM)** — AWS, Azure and GCP misconfiguration scanning, identity and network analysis, real-time cloud events, remediation queue — [Cloud Security](./cloud-security/index.md).
- **Container Security** — registry discovery and image scanning for AWS ECR, GCP Artifact Registry / GCR and Azure Container Registry (connected through a cloud account), and any other image — Docker Hub included — scanned by reference; SBOMs, image policies, and where each image runs — [Container Security](./security-scanning/containers/index.md).
- **Kubernetes Security** — cluster onboarding (EKS, GKE and AKS clusters are discovered from connected cloud accounts), scanning, fleet heat map and compliance — [Kubernetes Security](./security-scanning/kubernetes/index.md).
- **Asset Inventory** — a live catalog of cloud resources, clusters, repositories and Wazuh endpoints across accounts and regions — [Asset Inventory](./cloud-security/asset-inventory.md).
- **Attack Path Analysis** — graph-based discovery of exploitable paths to high-value assets, with an interactive graph explorer and blast radius from any node — [Attack Paths](./cloud-security/attack-paths.md).

### Compliance & Risk
Turn findings into audit-ready governance.
- **Compliance Posture** — a catalog of 27 frameworks (SOC 2, ISO 27001, PCI DSS, NIST CSF, SEBI CSCRF, India's DPDPA and more) on one SCF control library, with continuous scoring, evidence, drift detection and a "Why this status" explanation for every control — [Compliance & GRC](./compliance/index.md).
- **Risk Management** — a risk register with treatment plans, controls, appetite and KRIs, promoted from findings or imported — [Risk Management](./vulnerability-risk/risk-management/index.md).
- **Assessments** — guided, scored questionnaires (OWASP ASVS, NIST CSF 2.0, NIST SSDF, SOC 2, SAMM, ISO 27001 and others) with SCF-based auto-fill — [Assessments](./compliance/interactive-assessments.md).
- **Audit Reports** & **DPDP Compliance** — controls, findings, drift and remediation reports for auditors, frozen when issued and verifiable by their SHA-256 fingerprint; India's DPDP Act module (labelled beta in the product) with DPIAs, breach workflow and audit pack — [Audit Reports](./compliance/audit-reports.md) · [DPDP](./compliance/dpdp-privacy.md).

### Threat & Intelligence
Add context and automation to detection.
- **Threat Intelligence** — eight built-in feeds (CISA KEV, Abuse.ch URLhaus, AlienVault OTX, Feodo Tracker, SSL Blacklist, Blocklist.de, Spamhaus DROP, OpenPhish; URLhaus and OTX need an API key), each fetched on its own interval, IOC correlation against your assets and findings, KEV- and EPSS-weighted CVE prioritization, ATT&CK coverage — [Threat Intelligence](./ai-threat-intelligence/threat-intelligence.md).
- **AI Governance** — a registry of your AI systems with risk assessments, bias tests, incidents, discovery in your cloud and code (AIBOM) and an ISO 42001 posture — [AI Governance](./ai-threat-intelligence/ai-governance.md).

### Management
Configure, integrate, and administer.
- **Cloud Accounts** ([Connecting Cloud Accounts](./cloud-security/connecting-accounts.md)), **Integrations** (chat, email, PagerDuty, ticketing, Wazuh, Greenbone OpenVAS, SIEM forwarding, webhooks — [Integrations](./integrations/index.md)), **Unified Scheduler**, **Knowledge Base** (your policies as a searchable library that answers questions and fills security questionnaires — [Knowledge Base](./ai-threat-intelligence/knowledge-base.md)), and, from the account menu, **Team Management**, **API Keys** and **MFA** ([Platform Security](./authentication/index.md)). Pipelines use the REST API and the GitHub Action — [CLI & CI/CD](./cli-and-cicd.md).

Every module page has a **Help** button that opens task guides ("How do I…") checked against the shipped product, and module tabs are deep-linkable: the URL carries the open tab, so a link opens the same view.
