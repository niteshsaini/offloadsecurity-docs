# Offload Security

**Offload Security is a unified CNAPP, vulnerability management and compliance platform that consolidates findings across cloud, code, containers, Kubernetes, applications, on-premises infrastructure and Wazuh-monitored endpoints into one governed risk view.** These docs help you onboard, configure and operate it, as SaaS or fully on-premises.

## What you can do with it

Offload Security is organized into five areas that map directly to the product's left-hand navigation. Each line links to the section of these docs that covers it.

### Core Security
Run and review security testing from one place.
- **Dashboard** — security posture, metrics and top risks at a glance; the **Executive Dashboard** tab for leadership — [Reports & AI](./reports-and-ai/index.md).
- **Scanning** — web (OWASP ZAP, Nuclei), network (nmap), SSL/TLS (testssl.sh), security headers, API security testing and domain reconnaissance — [App & Infrastructure Scanning](./security-scanning/index.md).
- **Code Command Center** — SAST, secrets detection, dependency (SCA) and IaC scanning, SBOMs with **licence compliance**, fix pull requests — [Code Security](./security-scanning/code/index.md).
- **Vulnerability Management** — one triage queue across every source, risk scoring, SLA tracking, deduplication, remediation guidance — [Vulnerabilities & Risk](./vulnerability-risk/index.md).
- **Security Command Center** — agents that triage, prepare fixes and answer posture questions, with an approval-gated Auto-Fix Engine — [Security Command Center](./ai-threat-intelligence/ai-soc-agents.md).
- **Alerts** — the unified alert stream from every module, with routing to Slack, Teams, email and PagerDuty — [Alerts](./vulnerability-risk/alerts.md).

### Cloud & Infrastructure
Continuously assess everything you run in the cloud.
- **Cloud Security (CSPM)** — AWS, Azure and GCP misconfiguration scanning, identity and network analysis, real-time cloud events, remediation queue — [Cloud Security](./cloud-security/index.md).
- **Container Security** — registry discovery and image scanning (ECR, GCR / Artifact Registry, ACR, Docker Hub, private registries) with SBOMs and image policies — [Container Security](./security-scanning/containers/index.md).
- **Kubernetes Security** — cluster onboarding, scanning, fleet heat map and compliance — [Kubernetes Security](./security-scanning/kubernetes/index.md).
- **Asset Inventory** — a live catalog of cloud resources, clusters, repositories and Wazuh endpoints across accounts and regions — [Asset Inventory](./cloud-security/asset-inventory.md).
- **Attack Path Analysis** — graph-based discovery of exploitable paths to high-value assets — [Attack Paths](./cloud-security/attack-paths.md).

### Compliance & Risk
Turn findings into audit-ready governance.
- **Compliance Posture** — frameworks (SOC 2, ISO 27001, PCI DSS, NIST CSF, SEBI CSCRF, DPDP and more) on one SCF control library, with continuous scoring, evidence and drift detection — [Compliance & GRC](./compliance/index.md).
- **Risk Management** — a risk register with treatment plans, controls, appetite and KRIs, promoted from findings or imported — [Risk Management](./vulnerability-risk/risk-management/index.md).
- **Assessments** — guided, scored questionnaires (OWASP ASVS, NIST CSF 2.0, NIST SSDF, SOC 2, SAMM, ISO 27001 and others) with SCF-based auto-fill — [Assessments](./compliance/interactive-assessments.md).
- **Audit Reports** & **DPDP Compliance** — controls, findings, drift and remediation exports for auditors; India's DPDP Act module with DPIAs, breach workflow and audit pack — [Audit Reports](./compliance/audit-reports.md) · [DPDP](./compliance/dpdp-privacy.md).

### Threat & Intelligence
Add context and automation to detection.
- **Threat Intelligence** — nine curated feeds (CISA KEV, URLhaus, OTX, Feodo Tracker, PhishTank and more) fetched hourly, IOC correlation against your assets, KEV-weighted CVE prioritisation, ATT&CK coverage — [Threat Intelligence](./ai-threat-intelligence/threat-intelligence.md).
- **AI Governance** — a registry of your AI systems with risk assessments, incidents, discovery in your cloud and code (AIBOM), prompt-injection tests and an ISO 42001 posture — [AI Governance](./ai-threat-intelligence/ai-governance.md).
- **Knowledge Base** — your policies as a searchable library that answers questions and fills security questionnaires — [Knowledge Base](./ai-threat-intelligence/knowledge-base.md).

### Management
Configure, integrate, and administer.
- **Account Setup** ([Connecting Cloud Accounts](./cloud-security/connecting-accounts.md)), **Integrations** (Slack, Teams, email, PagerDuty, Jira, Wazuh, webhooks — [Integrations](./integrations/index.md)), **Unified Scheduler**, and, from the account menu, **Team Management**, **API Keys** and **MFA** ([Platform Security](./authentication/index.md)). Pipelines use the CLI and GitHub Action — [CLI & CI/CD](./cli-and-cicd.md).
