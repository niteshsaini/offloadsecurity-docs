# Adoption Guides

The rest of this documentation explains what each module does. This section answers a different question: **"What should we configure, in what order, and what does a good production setup look like?"**

Pick your entry point:

| Guide | Use it when |
|---|---|
| **[Quickstart](../getting-started.md)** | You have 30 minutes and want your first scan, finding, ticket, and alert. |
| **[First 7 Days](./first-7-days.md)** | You've finished the quickstart and want a day-by-day plan to reach an operating program. |
| **[Security Engineer journey](./security-engineer-journey.md)** | You own scanning, triage, and remediation, and want the pages that matter to you, in order. |
| **[Compliance Officer journey](./compliance-officer-journey.md)** | You own frameworks, assessments, evidence, and audits. |
| **[Recommended Production Configuration](./production-configuration.md)** | You want opinionated starting points for coverage, schedules, SLAs, alerting, and access. |

:::tip[These guides link, they don't restate]
Every step links to the reference page that documents it in full. If a step and a reference page ever disagree, the reference page wins.
:::
